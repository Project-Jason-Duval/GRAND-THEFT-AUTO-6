FAQ

Frequently asked questions about this fan hub.

How do the countdowns work?

The countdowns use UTC (Coordinated Universal Time) and update every second. They display days, hours, minutes, and seconds until the pre-download and launch dates. Status messages show "Upcoming," "Live," "Completed," or "Released" based on the current time.

Why UTC?

UTC is used as a universal reference that doesn't change with daylight saving time. Use the premiere schedule table to convert UTC to your local timezone.

What is OBS mode?

OBS mode is a streamlined view for streaming or recording. Add ?mode=obs to the URL to hide navigation, hero, and footer sections while enlarging countdown numbers. The background becomes transparent for overlay use.

How does localStorage work?

All your custom data (characters, locations, news, theories, summaries, trailers, screenshots) is saved in your browser's localStorage. This data persists across page reloads but is only stored on your device.

Can I edit countdown dates?

Countdown dates are hardcoded in the JavaScript file (script.js). To change them, edit the EVENTS constant in the code. This requires modifying the source files.

How do I add media?

Use the forms in the Trailers and Screenshots sections. Provide valid URLs for images and videos. Failed images show a fallback placeholder. Always include alt text for accessibility.

Can I add new sections?

Yes! This is a fan website template. You can add new sections by editing the HTML, CSS, and JavaScript files. Follow the existing patterns for consistency.

How do I clear saved data?

Use the "Clear Saved Data" button below. This removes only this website's localStorage data from your browser. It won't affect other websites or browser data.

How do I deploy this website?

Upload all three files (index.html, styles.css, script.js) to a web host. You can use GitHub Pages, Netlify, or any static hosting service. Keep all files in the same folder.
